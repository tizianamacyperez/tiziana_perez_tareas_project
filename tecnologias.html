Herramientas y tecnologías

Para desarrollar este proyecto voy a utilizar diferentes herramientas y lenguajes de programación.

  • HTML: para crear la estructura de las páginas.
  • CSS: para darle diseño y estilo al sitio.
  • PHP: para programar las funciones del sistema.
  • MySQL: para almacenar los datos de los usuarios.
  • Visual Studio Code: para escribir el código.
  • XAMPP: para ejecutar el servidor local.
  • phpMyAdmin: para administrar la base de datos.
  • PDO: para conectar PHP con MySQL.
